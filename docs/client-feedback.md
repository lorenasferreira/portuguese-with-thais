# Future project ideas

These ideas are recorded for possible future discussions. The current release covers private lessons and the booking flows documented in the [README](../README.md).

- **Downloadable learning resource.** A public PDF could be offered as a direct download. An email-gated version would require an agreed email platform and a separate decision about how subscriber data is handled.
- **Portuguese conversation club.** A small-group offer could use Brazilian culture and everyday topics as the basis for conversation. Audience level, schedule, group size, pricing and booking model remain open.
